## What was done (Next.js)

- `src/app/` holds one route folder per old React Router route. Each `page.tsx` is a thin wrapper that renders a view from `src/views/`.
- `src/pages/` was renamed to `src/views/`. Next.js reserves `src/pages/` for the old Pages Router.
- `src/lib/router.tsx` is a small shim that provides `Link`, `NavLink`, `Navigate`, `useNavigate`, `useParams`, `useLocation` and `useSearchParams` on top of `next/navigation`. The views kept their code and only changed one import line.
- `PublicLayout` and `DashboardLayout` take `children` instead of rendering `<Outlet />`. They are used by `app/(public)/layout.tsx`, `app/dashboard/layout.tsx`, `app/tutor/layout.tsx` and `app/admin/layout.tsx`.
- `src/app/providers.tsx` mounts the localStorage store **only in the browser**. Pages are therefore client-rendered for now, exactly like the SPA. Server rendering comes with the Prisma step.
- The `/about` and `/teach` redirects live in `next.config.ts`. Unknown URLs hit `app/(public)/[...notFound]`.
- Removed: Vite, `react-router-dom`, `index.html`, `main.tsx`, `App.tsx`, `vercel.json` and `public/_redirects`. Next.js does not need SPA rewrites.

## Big picture

```
 NOW                                    TARGET
 ─────────────────────────────          ─────────────────────────────────────
 Next.js (client-rendered)              Next.js
  └─ views → useStore()                  ├─ Server Components  → Prisma queries
      └─ localStorage (DB JSON)          ├─ Server Actions     → Prisma mutations
                                         └─ Auth.js session (cookie)
                                                │
                                         PostgreSQL
```

## Things that change on purpose in the backend step

- **Passwords** are hashed (bcrypt) instead of stored in plain text.
- **IDs** are generated by the database (`cuid()`), not by `uid()`.
- **Dates** become real `DateTime` columns instead of `YYYY-MM-DD` strings.
- **Carts and wishlists** become tables instead of `Record<userId, courseId[]>`.
- **Course curriculum** is stored as `Section` and `Lesson` rows instead of nested JSON.
- **Checkout** is still a mock (no payment provider). See `05-data-layer.md` for where Stripe would go.
- **"Reset demo data"** (admin) becomes `npm run db:reset` or an admin-only action that re-runs the seed.
